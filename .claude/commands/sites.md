# sites

Every site: its jurisdiction, whether it is insured, self-insured or an ACC Accredited Employer, the insurer, the return to work coordinator, workers, open claims and overdue deadlines.

Run `node scripts/claims.mjs sites`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
