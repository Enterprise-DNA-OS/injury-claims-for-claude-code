# draft-rtw-plan

Draft a return to work plan for signing, from the plan and the current certificate. Written to drafts/.

Run `node scripts/claims.mjs draft-rtw-plan <plan>`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
