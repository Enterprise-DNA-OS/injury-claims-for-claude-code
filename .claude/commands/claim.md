# claim

One claim in full: where it stands, deadlines, certificates, plans, payments, actions and the last ten case notes. Find it by claim ref, the insurer's claim number or the worker's name.

Run `node scripts/claims.mjs claim <claim>`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read this before writing anything about a claim.
