# settings

The house rules: quiet days, certificate warning days, plan days, reimbursement chase days, and any weekly maximums set.

Run `node scripts/claims.mjs settings`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
