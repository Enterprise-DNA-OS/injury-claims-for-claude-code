# weekly-review

Write the Monday review to drafts/: what needs a person, every open claim, and money by site.

Run `node scripts/claims.mjs weekly-review`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Then summarise it in five lines: the worst legal breach, certificates and plans, money waiting, quiet claims.
