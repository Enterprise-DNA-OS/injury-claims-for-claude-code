# deadlines

Every statutory deadline on an injury or claim, open ones first, with the rule behind each. --site to filter, --all to include the ones already met.

Run `node scripts/claims.mjs deadlines`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
