# site

Everything about one site: open claims, deadlines not met, and injuries in the last 90 days.

Run `node scripts/claims.mjs site <site>`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
