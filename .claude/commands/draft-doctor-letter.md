# draft-doctor-letter

Draft the letter to the treating doctor offering suitable duties (--duties). Written to drafts/, never sent.

Run `node scripts/claims.mjs draft-doctor-letter <claim>`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
