# certificates

The current certificate on every open claim: capacity, hours, restrictions, when it runs out.

Run `node scripts/claims.mjs certificates`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
