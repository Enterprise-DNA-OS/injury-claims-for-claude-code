# export

Export every record to one JSON file the business owns. It holds confidential injury and health information: keep it as securely as the database.

Run `node scripts/claims.mjs export`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
