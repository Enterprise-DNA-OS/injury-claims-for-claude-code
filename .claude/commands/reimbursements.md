# reimbursements

Money paid that the insurer or agent owes back, and how long it has waited. --open hides what has come back.

Run `node scripts/claims.mjs reimbursements`. Add `--json` when you need every field. Resolve the worker, injury, claim, plan or site by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
